' ----------------------------------------------------------------------------------
' Relationships
' ----------------------------------------------------------------------------------

' Patient has a specific patient category
Patient "1" -- "1" PatientCategory : has >

' A patient receives multiple treatments during their stay
Patient "1" -- "*" Treatment : receives >

' An invoice is generated for one patient
Invoice "1" -- "1" Patient : for >

' An invoice aggregates multiple treatments
Invoice "1" -- "*" Treatment : aggregates >

' Each treatment uses a specific pricing strategy to calculate its cost
Treatment "1" -- "1" PricingStrategy : uses >

' Each patient category determines which billing policy applies
PatientCategory "1" -- "1" BillingPolicy : determines >

' The platform manages patients and generates invoices
HospitalAdministrationPlatform "1" --> "1" Patient : manages >
HospitalAdministrationPlatform "1" --> "1" Invoice : generates >

' ----------------------------------------------------------------------------------
' Notes for clarity and design justification
' ----------------------------------------------------------------------------------

note "Strategy Pattern: Allows dynamic interchangeability of billing logic at runtime. New policies can be added without modifying core Invoice or PatientCategory classes." as N1
BillingPolicy .. N1

note "Strategy Pattern: Enables flexible pricing rules for different treatment types. Pricing logic can be adjusted independently of Treatment definitions." as N2
PricingStrategy .. N2

note "Ensures strict separation between patient information, pricing modules, and billing policies, promoting loose coupling and extensibility." as N3
Patient .. N3
PricingStrategy .. N3
BillingPolicy .. N3

note "Money is a Value Object to handle currency amounts, preventing primitive obsession and ensuring type safety for financial calculations." as N4
Money .. N4

note "The HospitalAdministrationPlatform acts as an orchestrator, providing a high-level interface for core system functionalities." as N5
HospitalAdministrationPlatform .. N5
