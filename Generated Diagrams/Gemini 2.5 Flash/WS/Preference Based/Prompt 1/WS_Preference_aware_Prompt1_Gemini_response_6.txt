' Abstract Sensor Class - Base for different sensor types
abstract class Sensor {
    - sensorId : string
    - manufacturer : string
    - sensorType : string ' e.g., "Temperature", "Humidity", "Pressure"
    + Sensor(id : string, type : string, manufacturer : string)
    + getSensorId() : string
    + getSensorType() : string
    + getManufacturer() : string

}
note bottom of Sensor : Abstract base for specific sensor types.\nEach concrete sensor type implements 'readRawValue()'\nto produce data in its native format.

' Raw Measurement Class - Data exactly as received from a sensor before normalization
class RawMeasurement {
    - rawMeasurementId : string
    - sensorId : string
    - timestamp : DateTime
    - nativeValue : string ' e.g., "25.3C", "{'temp':25.3, 'unit':'C'}"

    + RawMeasurement(sensorId : string, ts : DateTime, value : string, format : string)
    + getRawMeasurementId() : string
    + getSensorId() : string
    + getTimestamp() : DateTime
    + getNativeValue() : string
    + getNativeFormatIdentifier() : string
}
