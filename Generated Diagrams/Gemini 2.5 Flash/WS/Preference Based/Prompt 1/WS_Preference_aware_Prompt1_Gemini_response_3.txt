' Overall context note
note "Distributed Environmental Monitoring Platform" as PlatformContext
  This diagram models the core components for
  aggregating and processing telemetry from
  heterogeneous weather stations.
end note
PlatformContext .. MonitoringPlatform

' 1. Operator Class: Represents the entities operating weather stations.
class Operator {
    - id : string
    - name : string
    - type : string <<enum>> {Government, Research, Infrastructure}
    --
    + getOperatorInfo() : string
}

' 2. WeatherStation Class: Represents a physical weather station.
class WeatherStation {
    - stationId : string
    - location : string
    - lastTransmissionTime : DateTime
    - transmissionFrequencyMinutes : int
    --
    + establishConnection() : bool
    + requestTelemetry() : List<RawMeasurement>
    + updateTransmissionFrequency(newFrequency : int)
}

' 3. Sensor Class: Represents a sensor within a weather station.
class Sensor {
    - sensorId : string
    - type : string <<enum>> {Temperature, Humidity, Pressure, WindSpeed, etc.}
    - manufacturer : string
    - nativeFormat : string <<enum>> {JSON, XML, CSV, Binary}
    --
    + getSensorDetails() : string
}

' 4. RawMeasurement Class: Represents sensor data in its native, unnormalized format.
class RawMeasurement {
    - measurementId : string
    - sensorId : string
    - timestamp : DateTime
    - rawValue : string ' Stores data in native format (e.g., JSON string, CSV line)
    - nativeUnit : string ' Unit as reported by the sensor
    --
    + getRawData() : string
}

' 5. NormalizedMeasurement Class: Represents sensor data after normalization.
class NormalizedMeasurement {
    - measurementId : string
    - sensorId : string
    - timestamp : DateTime
    - value : double
    - standardizedUnit : string ' Standardized unit (e.g., Celsius, hPa)
    --
    + getValue() : double
    + getStandardizedUnit() : string
}

' 6. DataNormalizer Class: Responsible for converting raw data to a standardized format.
class DataNormalizer {
    --
    + normalize(rawMeasurement : RawMeasurement) : NormalizedMeasurement
    - parseNativeFormat(data : string, format : string) : Map<string, string>
    - convertUnits(value : double, fromUnit : string, toUnit : string) : double
}

' 7. DataIngestionService Class: Manages the process of fetching, normalizing, and storing data.
class DataIngestionService {
    --
    + ingestDataFromStation(station : WeatherStation) : List<NormalizedMeasurement>
    - fetchRawData(station : WeatherStation) : List<RawMeasurement>
    - processRawData(rawMeasurements : List<RawMeasurement>) : List<NormalizedMeasurement>
    - storeNormalizedData(normalizedMeasurements : List<NormalizedMeasurement>)
}

' 8. MonitoringPlatform Class: The central system orchestrating the entire monitoring process.
class MonitoringPlatform {
    - platformId : string
    - name : string
    --
    + startMonitoring()
    + stopMonitoring()
    + deployStation(station : WeatherStation)
    + retrieveHistoricalData(stationId : string, startTime : DateTime, endTime : DateTime) : List<NormalizedMeasurement>
}

' Relationships

' An Operator operates zero or more WeatherStations. A WeatherStation is operated by exactly one Operator.
Operator "1" -- "0..*" WeatherStation : operates >

' A WeatherStation hosts one or more Sensors. A Sensor belongs to exactly one WeatherStation.
WeatherStation "1" *-- "1..*" Sensor : hosts >

' A Sensor generates zero or more RawMeasurements over time. A RawMeasurement is generated by exactly one Sensor.
Sensor "1" --> "0..*" RawMeasurement : generates >

' A RawMeasurement is processed by a DataNormalizer to produce a NormalizedMeasurement.
RawMeasurement "1" --> "1" DataNormalizer : is processed by >
DataNormalizer "1" --> "1" NormalizedMeasurement : produces >

' The DataIngestionService interacts with WeatherStations to fetch raw data.
DataIngestionService "1" --> "0..*" WeatherStation : interacts with >

  Establishes link, requests,
  and receives raw data.
end note

' The DataIngestionService uses the DataNormalizer to process raw data.
DataIngestionService "1" --> "1" DataNormalizer : uses >

' The DataIngestionService ingests and stores NormalizedMeasurements.
DataIngestionService "1" --> "0..*" NormalizedMeasurement : ingests and stores >

' The MonitoringPlatform manages (contains) the DataIngestionService.
MonitoringPlatform "1" *-- "1" DataIngestionService : manages >

' The MonitoringPlatform oversees and can deploy/manage WeatherStations.
MonitoringPlatform "1" --> "0..*" WeatherStation : oversees >

' The MonitoringPlatform aggregates and provides access to NormalizedMeasurements.
MonitoringPlatform "1" --> "0..*" NormalizedMeasurement : aggregates >
